# classroom

Приватный набор правил, навыков и скриптов для учебных заданий и работы с текстом.
Исходный снимок доступных материалов сделан 2 октября 2026 года.
Предметные правила дополнены 3 октября 2026 года.

Полное руководство для Codex: [установка и использование](docs/codex-setup.md).
Готовая основа проектных инструкций: [шаблон AGENTS.md](docs/AGENTS.example.md).

## Состав

| Категория | Навыки |
| --- | --- |
| Учебный процесс | `classroom-workflow`, `skill-state` |
| Текст и ввод | `text`, `print`, `humanizer`, `humanizer-ru` |
| Google Workspace | `gog`, `google-drive`, `google-docs`, `google-drive-comments`, `google-sheets`, `google-slides` |
| Файлы | `presentations`, `spreadsheets`, `pdf`, `pdf-runtime` |
| Браузер | `playwright`, `playwright-interactive` |
| Учебные медиа | `youtube-conversation`, `transcribe`, `speech`, `imagegen`, `video` |

- [AGENTS.md](AGENTS.md): основные правила выполнения учебных заданий.
- [Настройки](config/classroom.json): язык, оформление, ввод, скриншоты и отправка.
- [Рабочий порядок](docs/workflow.md): чтение, выполнение и проверка задания.
- [Предметные правила](docs/subjects/index.md): отдельные подсказки для курсов и тем;
  требования текущего задания всегда определяют объём работы.
- [Каталог](inventory.json): происхождение файлов, исходные и экспортные SHA-256.
- [Ограничения переноса](docs/export-limits.md): отсутствующие скрипты и ограниченные лицензии.
- `skills/`: навыки с их скриптами, справочниками, шаблонами и лицензиями.
- `third_party/`: сведения об авторах и лицензиях установленных плагинов.

## Использование в новом проекте

1. Клонируйте репозиторий: `git clone git@github.com:siriushex/classroom.git`.
2. Откройте папку проекта и используйте `AGENTS.md` как инструкции для помощника.
3. Для Codex подключите нужные навыки из `skills/` ссылками в `.agents/skills/`.
   Начните с `classroom-workflow`, `text`, `print` и `skill-state`.
   Команды, описание всех 23 навыков и примеры запросов приведены в
   [полном руководстве](docs/codex-setup.md).
   Копирование папки само по себе не подключает инструменты, плагины или аккаунты.
4. Настройте собственные учётные записи Google и требуемые плагины локально.
   Аккаунты, ключи и токены храните вне Git. Для примеров переменных есть `.env.example`.
5. Прочитайте зависимости конкретного навыка перед запуском его скриптов.
   Доступность инструментов и разрешения проверяйте в текущей сессии.

Файл инструкций называется `AGENTS.md`. Для работы в другом проекте добавьте туда
правила из [шаблона](docs/AGENTS.example.md) и абсолютный путь к набору Classroom.
`config/classroom.json` содержит предпочтения, которые должен прочитать агент;
он не является автоматически исполняемой конфигурацией Codex.
Папки `pdf` и `pdf-runtime` объявляют одинаковое имя `pdf`: выберите один вариант.

Для базовых проверок нужен Python 3. Для побуквенного ввода нужны macOS,
`osascript`, `pbpaste`, `pbcopy` и разрешение Accessibility для Python/терминала.
Для отдельных навыков могут понадобиться Node.js, LibreOffice, FFmpeg, Google
Workspace CLI, библиотеки PDF, подключённые сервисы и API. Они не устанавливаются автоматически.
Сервисные пути `/mnt/data`, `artifact_tool`, `artifact_session` и названия инструментов
в копиях навыков относятся к исходной среде. Эти навыки требуют соответствующей среды;
они не являются самостоятельными программами для любого компьютера.

## Проверка без ввода в приложения

```sh
python3 scripts/validate_bundle.py
python3 -m unittest discover -s skills/print/tests -v
python3 skills/print/scripts/type_text.py --text 'Українська мова' --dry-run
```

`--dry-run` только считает действия и не отправляет символы в приложение.
Реальный ввод допускается после проверки и подтверждения конкретного документа,
места ввода и окончательного текста. Скрипт не сдаёт задания.

Для следующего свободного имени скриншота:

```sh
python3 scripts/next_screenshot_name.py
```

Этот помощник выводит путь `~/Downloads/testN.png`. Он не делает скриншот,
не создаёт файл и не прикрепляет изображение к Classroom.

## Лицензии и границы экспорта

Сохранены исходные лицензии и сведения об авторах. Общая лицензия не заменяет
лицензии отдельных компонентов. Собственные инструкции проекта основаны на
правилах пользователя. Изменения экспортированных копий перечислены в каталоге.
Навык `documents` не скопирован: его лицензия запрещает хранение копий вне сервиса.
Для него используйте официальный плагин. Исторические удалённые школьные скрипты
не восстановлены; их список находится в [ограничениях переноса](docs/export-limits.md).

Учебные работы, оценки, базы данных, скриншоты, профили браузера и секреты
в этот набор не включены. Репозиторий не запускает рассылку или сдачу работ.
