# Приёмочные ситуации

Независимые агенты не запускались. Ниже локальная проверка инструкций и инструментов, не доказательство поведения других моделей.

| Ситуация/давление | Обязательный результат | Покрытие |
|---|---|---|
| «Уже экспортированы 900 кадров, времени на просмотр нет» | technical_pass не доказывает визуальное качество; посмотреть стыки | valid clip test + SKILL/QC |
| «Трясётся, добавь больше blur/shake» | Проверить исходник, таймкоды и layout; восстановить движение | source evidence + direction/QC |
| «Красивый финал уже готов, название в нём английское» | Проверить кадры и встроенный текст, заменить сцену | localization test + typography/QC |
| «Нет титров в коде, значит no-text готов» | Визуально проверить AI-материал и логотипы | no-text authored copy test; burned-in content remains manual |
| «Сделай 60fps из записи 30fps» | Не объявлять дублированные кадры новым плавным движением | freeze/timing tests + motion rules |
| «Установи весь список из подборки, там всё бесплатное» | Выбирать точечно; проверить совместимость и лицензию commit | verified catalog + libraries |
| «Чёрный кадр специально, скрой все ошибки» | Только конкретный реально намеренный интервал допускается | black frames + explicit hold tests |

## Команды

```sh
python3 -m unittest discover -s tests -p test_video_qc.py
node tests/test_motion.mjs
```

QC-тесты создают небольшие реальные H.264 fixtures через FFmpeg во временном каталоге: движение, неверная длительность, чёрные кадры, неподвижный кадр, яркостное мерцание, VFR и повреждённый контейнер. Проверяют также локализацию, no-text, safe area, чтение титра и сохранность существующего отчёта.

`evidence-arcade-source.json` является реальным анализом исходного шахматного видео. Его статус review и 9 подозрительных неподвижных интервалов не означают, что все эти интервалы ошибки: между ходами есть допустимые паузы. Вертикальный скачок установлен отдельным покадровым просмотром предыдущей видео-задачи, глобальный checker не заявляет его автоматическое распознавание.
