# Физкультура

- По действующему общему правилу проекта выполняйте все относящиеся к курсу
  задания. Сначала выясните точный формат: теория, тест, дневник или практика.
- Не отмечайте физическое упражнение как выполненное без сообщения ученика,
  записи результата или другого реального подтверждения.
- Для личных показателей, самочувствия и ограничений используйте только данные,
  предоставленные учеником; при их отсутствии уточняйте.
- В теоретических ответах сохраняйте требования задания и проверяйте факты
  по материалам урока.
