# Технологии

- Уточняйте требуемое изделие или проект, материалы, инструменты, размеры,
  этапы и критерии оценки из задания.
- План работы описывайте в выполнимой последовательности с учётом указанных
  правил безопасности. Не подменяйте требуемый практический результат описанием.
- Для чертежей и таблиц сохраняйте единицы, размеры, подписи и нумерацию.
- Фотографию готового изделия, расход материалов и ход практической работы
  указывайте только по реально предоставленным данным.
