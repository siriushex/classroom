# Классное общение

- Отличайте объявление и справочный материал от задания, на которое нужен ответ.
  Не создавайте работу, если курс только сообщает информацию.
- Сохраняйте даты, ссылки, имена и организационные условия из сообщения.
- Для личной рефлексии, планов и опыта используйте только сведения ученика.
- Если требуется ответ учителю, приглашение или иная отправка, соблюдайте
  отдельные правила разрешения из корневого `AGENTS.md`.
