# География

- Уточняйте регион, дату данных, тип карты и её легенду. Проверяйте названия,
  масштаб, координаты и единицы измерения.
- Для числовых показателей обозначайте год и источник, когда они важны для
  ответа; не смешивайте данные разных периодов без объяснения.
- При анализе карты или диаграммы выводите только то, что подтверждается
  изображением или данными. Не придумывайте полевые наблюдения.
- Если задание требует расчёта, показывайте исходные значения и результат
  с единицами.
