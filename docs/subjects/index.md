# Предметные правила

Выбирайте предмет по содержанию **текущего задания**, а название курса используйте
как подсказку. В объединённом курсе украинского языка и литературы читайте
соответствующий файл; если задание охватывает обе части, читайте оба. При
неоднозначности сначала изучите вложения, а затем уточните тему у пользователя.
Эти правила помогают проверять ответы и не добавляют заданий от имени учителя.

формулировка задания имеют приоритет.
