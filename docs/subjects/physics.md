# Физика

- Для расчётной задачи сохраните обозначения из условия, запишите данные и
  искомую величину, выберите подходящую формулу и покажите подстановку.
- Приводите совместимые единицы, при необходимости переводите данные в СИ;
  проверяйте размерность и правдоподобие результата.
- Для графиков и опытов используйте только выданные измерения, погрешности и
  наблюдения. Не подменяйте эксперимент теоретическим ожиданием.
- Теоретическое объяснение связывайте с физическим законом, который изучается
  в текущей теме.
