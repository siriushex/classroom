# Информатика

- Сохраняйте точный язык программирования, имя файла, формат данных и требования
  к выводу из задания. Не меняйте интерфейс или алгоритм без причины.
- Для кода проверяйте запуск на подходящих примерах, включая граничные случаи,
  когда среда доступна. Показывайте фактический результат проверки.
- Для работы в приложении проверяйте сохранённый файл и видимое состояние после
  каждого существенного изменения.
- Не называйте программу, сайт или тест работающими, если проверка не состоялась.
