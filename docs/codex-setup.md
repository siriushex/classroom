# Classroom в Codex: установка, навыки, AGENTS.md и рабочий порядок

Руководство подготовлено 3 октября 2026 года для https://github.com/siriushex/classroom.
Основа: экспорт `51f1fc595aa9ac081bb23ce03310085dd7b119be` от 2 октября 2026 года.
Репозиторий приватный. В исходном наборе 23 папки навыков.

Проверка исходного набора, тестов ввода и пробного запуска описана ниже.
Зависимости, авторизацию и доступность инструментов проверяйте в своей среде.

## 1. Что именно находится в репозитории

| Компонент | Назначение |
| --- | --- |
| `AGENTS.md` | Общие правила агента в учебном проекте |
| `skills/*/SKILL.md` | Инструкции отдельных навыков |
| `skills/*/scripts/` | Вспомогательные программы, если они предусмотрены |
| `config/classroom.json` | Предпочтения для оформления, ввода, скриншотов и сдачи |
| `docs/workflow.md` | Последовательность работы с заданием |
| `docs/subjects/index.md` | Выбор отдельных правил по теме школьного задания |
| `docs/export-limits.md` | Ограничения переноса и список отсутствующих старых компонентов |
| `inventory.json` | Каталог экспортированных файлов и контрольные суммы |
| `scripts/validate_bundle.py` | Проверка целостности набора и отдельных требований безопасности |
| `scripts/next_screenshot_name.py` | Выбор свободного имени скриншота |

Навык задаёт рабочий порядок. Подключённый инструмент выполняет действие.
Поэтому копирование `google-docs/SKILL.md` не подключает Google, а копирование
`playwright/SKILL.md` не даёт доступ к уже открытой вкладке Chrome.

Обычная папка `skills/` сама по себе не является основным каталогом обнаружения
локальных навыков в текущей документации Codex. Для проекта используется
`.agents/skills/`, для навыков пользователя используется `~/.agents/skills/`.
Codex поддерживает символические ссылки на папки навыков. [Официальное описание](https://developers.openai.com/codex/skills).

## 2. Рекомендуемая установка в отдельный учебный проект

Лучше открыть `classroom` как отдельный проект Codex. Так учебный рабочий порядок
не смешивается с инструкциями торговых, серверных и других проектов.

Для установки нужны Git и Python 3. GitHub CLI нужен только для варианта клонирования
через `gh`. macOS необходима для скрипта `$print`; остальные возможности зависят
от своих инструментов и среды.

### Шаг 1. Получить репозиторий

Если GitHub CLI уже авторизован в аккаунте с доступом:

```sh
gh repo clone siriushex/classroom "$HOME/Documents/classroom"
cd "$HOME/Documents/classroom"
```

Если GitHub CLI ещё не авторизован, сначала выполните `gh auth login` и пройдите
авторизацию в браузере. Токен не нужно вставлять в чат.

Альтернатива с настроенным SSH-доступом к GitHub:

```sh
git clone git@github.com:siriushex/classroom.git "$HOME/Documents/classroom"
cd "$HOME/Documents/classroom"
```

Выберите один вариант. Если папка уже содержит репозиторий, повторно клонировать
его в неё не нужно. Все следующие команды выполняйте из корня своей копии.

### Шаг 2. Проверить набор

Из корня репозитория:

```sh
python3 scripts/validate_bundle.py
python3 -m unittest discover -s skills/print/tests -v
python3 skills/print/scripts/type_text.py --text 'Українська мова' --dry-run
```

На проверенной версии валидатор сообщил `ok: true`, 23 навыка и отсутствие ошибок.
Два теста `$print` прошли. Пробный запуск сообщил 15 действий без ввода в приложение.
Эти проверки подтверждают состояние набора и вспомогательного кода. Доступ к Google,
правильное поле ввода и успешную сдачу нужно проверять отдельно в текущем задании.

### Шаг 3. Подключить четыре основных навыка

Для первого запуска достаточно `classroom-workflow`, `text`, `print` и `skill-state`.
Следующие команды создают ссылки и сохраняют уже существующие записи:

```sh
mkdir -p .agents/skills

for skill in classroom-workflow text print skill-state; do
  target=".agents/skills/$skill"
  if [ -e "$target" ] || [ -L "$target" ]; then
    printf 'Уже существует, проверьте: %s\n' "$target"
  else
    ln -s "../../skills/$skill" "$target"
  fi
done
```

Если команда сообщает об уже существующей записи, проверьте, куда она ведёт.
Сообщение само по себе не подтверждает, что нужный навык подключён.

После этой команды структура будет примерно такой:

```text
classroom/
  AGENTS.md
  config/classroom.json
  docs/workflow.md
  skills/
    classroom-workflow/SKILL.md
    text/SKILL.md
    print/SKILL.md
    skill-state/SKILL.md
  .agents/skills/
    classroom-workflow -> ../../skills/classroom-workflow
    text -> ../../skills/text
    print -> ../../skills/print
    skill-state -> ../../skills/skill-state
```

Ссылки сохраняют соседние пути вида `../text/SKILL.md` и позволяют использовать
оригинальные скрипты без второй копии. Установка четырёх навыков не удаляет остальные
19 папок из репозитория.

### Шаг 4. При необходимости подключить остальные навыки

Из корня репозитория можно зарегистрировать все папки, кроме дублирующего `pdf-runtime`:

```sh
mkdir -p .agents/skills

for source in skills/*; do
  [ -f "$source/SKILL.md" ] || continue
  skill="${source##*/}"
  [ "$skill" = "pdf-runtime" ] && continue
  target=".agents/skills/$skill"
  if [ -e "$target" ] || [ -L "$target" ]; then
    printf 'Уже существует, проверьте: %s\n' "$target"
  else
    ln -s "../../skills/$skill" "$target"
  fi
done
```

Причина исключения: обе папки `pdf` и `pdf-runtime` содержат `name: pdf`.
По текущей документации Codex одноимённые навыки не объединяются и могут показываться
как отдельные варианты. Для обычного локального запуска здесь выбран `skills/pdf`.
Если нужны возможности второго варианта, укажите агенту точный файл
`skills/pdf-runtime/SKILL.md`, либо осознанно замените регистрацию первого варианта.
Переименование только папки не меняет поле `name`.

Кроме того, в `presentations` имя навыка записано как `Presentations`, в
`spreadsheets` как `Spreadsheets`. В меню выбирайте фактически показанное имя.
Установленный официальный плагин может добавлять к нему свой префикс.

### Шаг 5. Открыть правильную папку в Codex

В приложении добавьте или откройте папку `classroom` как проект и начните новый чат.
В CLI можно запустить `codex` из её корня.

Codex обычно обнаруживает изменения навыков автоматически. Если они не появились,
перезапустите приложение или начните новую сессию. После изменения `AGENTS.md`
тоже удобно начать новый чат, чтобы заново собрать инструкции.

Проверочный запрос:

```text
Проверь настройку этого учебного проекта без изменений в Google.
Назови рабочую папку и активные источники инструкций.
Покажи, доступны ли classroom-workflow, text, print и skill-state.
Прочитай config/classroom.json и docs/workflow.md.
Проверь доступные инструменты Google и браузера, сообщи только отсутствующие зависимости.
```

В CLI и IDE есть `/skills` и выбор навыка через `$`. В настольном интерфейсе
используйте доступный список или подсказки навыков. Если явного выбора нет,
попросите прочитать точный `SKILL.md`: это позволяет применить инструкции в текущем
чате, но не регистрирует навык постоянно.

## 3. Как использовать набор в другом проекте

Если школьные файлы лежат в другом проекте, доступны два подхода.

1. Подключить нужные папки в `<проект>/.agents/skills/` ссылками на постоянную
   копию `classroom/skills/`, затем добавить в проектный `AGENTS.md` абсолютный
   путь к правилам и конфигурации Classroom.
2. Подключить выбранные навыки в `~/.agents/skills/`, чтобы они были доступны
   во всех проектах. Общие учебные правила всё равно привязать к конкретному проекту.

Пример регистрации четырёх навыков для пользователя:

```sh
bundle="$HOME/Documents/classroom"
mkdir -p "$HOME/.agents/skills"

for skill in classroom-workflow text print skill-state; do
  target="$HOME/.agents/skills/$skill"
  if [ -e "$target" ] || [ -L "$target" ]; then
    printf 'Уже существует, проверьте: %s\n' "$target"
  else
    ln -s "$bundle/skills/$skill" "$target"
  fi
done
```

Этот вариант сработает, пока исходная папка существует по указанному пути.
Перед установкой проверьте одноимённые навыки из других папок и плагинов.
Сохраняйте связанные соседние навыки, если их требует выбранный `SKILL.md`.

В другом проекте `classroom-workflow` может неоднозначно понимать слова «корневой
AGENTS.md». Поэтому в инструкциях того проекта явно задайте, где находится набор:

```md
## Classroom

- Набор Classroom находится в /absolute/path/classroom.
- Для учебных задач прочитать /absolute/path/classroom/AGENTS.md,
  /absolute/path/classroom/config/classroom.json и
  /absolute/path/classroom/docs/workflow.md.
- После чтения задания выбрать предмет в
  /absolute/path/classroom/docs/subjects/index.md и прочитать нужный файл.
- Применять classroom-workflow и text в режиме Classroom.
- Скрипты и справочники брать из фактической папки выбранного навыка.
- Личные ответы хранить в work/ текущего учебного проекта.
```

Замените `/absolute/path/classroom` на абсолютный путь к своей копии набора.

## 4. Что писать в AGENTS.md

Имя файла: **`AGENTS.md`**, во множественном числе. Файл `Agent.md` без специальной
настройки не является стандартным именем инструкций Codex.

Codex собирает инструкции из глобального файла `~/.codex/AGENTS.md` и проектных
файлов от корня проекта до рабочей папки. `AGENTS.override.md` имеет приоритет
над обычным `AGENTS.md` в той же папке. Более близкие к рабочей папке правила
уточняют предыдущие. В глобальном файле лучше держать общие предпочтения, а правила
школьных предметов оставить в учебном проекте. [Официальный порядок](https://developers.openai.com/codex/guides/agents-md).

`AGENTS.md` не устанавливает навыки, программы или подключённые сервисы.
Запись `$text` в нём задаёт предпочтение для выбора навыка. Каталог обнаружения
и реальные инструменты настраиваются отдельно.

### Блок для добавления в существующий AGENTS.md

В репозитории уже есть подробный `AGENTS.md`. Его не нужно заменять целиком.
Следующий блок делает выбор навыков и чтение конфигурации более явными:

```md
## Работа с Google Classroom

### Начало задачи

- Для учебной задачи использовать classroom-workflow.
- Прочитать config/classroom.json и docs/workflow.md относительно корня
  этого учебного проекта. При отсутствии файла сообщить точный недостающий путь.
- Проверить курс, название задания, ссылку, язык, вложения и доступ к документу.
- Выбрать предметные правила в docs/subjects/index.md по теме задания;
  название объединённого курса не обязывает читать правила всех его предметов.
- Выполнять точные требования задания, сохранять вопросы и нумерацию.
- Для многошаговой работы использовать skill-state в текущем чате.

### Выбор навыков

- Ответы готовить с text в режиме Classroom.
- Google-файлы находить через google-drive и доступный подключённый инструмент.
- Для Google Документов применять google-docs, таблиц google-sheets,
  презентаций google-slides.
- По явному запросу на побуквенный ввод использовать print.
- Для PDF использовать выбранный вариант pdf; при наличии дублей указать путь.
- Для локальных презентаций и таблиц использовать presentations или spreadsheets
  только с доступной поддерживаемой средой исполнения.
- Для YouTube, аудио, озвучки и видео выбирать соответствующий навык по заданию.
- Скрипты запускать из реального расположения навыка. Не подставлять старые
  сервисные пути, если они отсутствуют на этом компьютере.

### Ответы

- Писать на языке задания, понятно и на уровне ученика 15 лет.
- Украинские ответы писать литературным украинским языком.
- Ответ помещать сразу под своим вопросом.
- Не добавлять Відповідь:, Відповідь. и общий заголовок Відповіді,
  если этого не требует задание или пользователь.
- В таблицах отмечать выбранный вариант знаком +.
- Века обозначать римскими цифрами, например XXI.
- Не использовать длинное тире; сохранять обязательные дефисы.
- Не придумывать личные факты, источники и результаты тестов.
- Проверять смысл, факты, грамматику и полноту перед внесением текста.
- humanizer-ru применять выборочно только к готовым русским текстам.

### Внесение текста

- Разрешённый способ редактирования определять по текущему запросу пользователя.
- Перед print показать окончательный текст и подтвердить конкретный документ,
  место ввода и этот текст непосредственно перед набором.
- После каждого ответа проверить правильное место, сохранность вопроса
  и сохранение изменений.
- Отсутствие прав не обходить. При разрешённом создании копии проверить,
  что ответы относятся к копии, которую затем можно прикрепить к заданию.

### Упражнения и сдача

- Выполнить относящиеся к заданию упражнения и проверить настоящий результат.
- Реальные скриншоты сохранять в ~/Downloads как test1.png, test2.png и далее.
- Не перезаписывать скриншоты и не прикреплять их к Classroom без нового указания.
- По умолчанию подготовить работу без сдачи.
- Прикрепление, приглашение, изменение доступа и сдачу выполнять только
  в разрешённом пользователем объёме и с обязательными подтверждениями инструмента.
- Действующее разрешение на сдачу конкретного задания или курса учитывать
  без повторного запроса, если дополнительные подтверждения не требуются.
- После сдачи проверить видимый статус Classroom и сообщить ссылку и результат.

### Рабочие файлы и секреты

- Ответы и личные документы хранить в work/, checkpoint в отдельной папке state/.
- Не добавлять учебные ответы, оценки, токены, ключи и профили браузера в Git.
- В итогах различать: подготовлено, внесено, прикреплено и сдано.
```

Названия каталогов `presentations` и `spreadsheets` здесь служат маршрутизацией.
При явном упоминании выбирайте фактический навык `Presentations` или `Spreadsheets`
из своего меню.

Готовый шаблон: [AGENTS.example.md](AGENTS.example.md). Для нового учебного проекта
его можно использовать как основу `AGENTS.md`, предварительно проверив свои
разрешения и пути. В существующий файл добавляйте нужные правила без удаления
инструкций пользователя.

### Короткая запись в глобальный AGENTS.md

```md
## Учебные задачи

- Для Classroom использовать правила текущего учебного проекта.
- Для ответов применять text в режиме Classroom и язык задания.
- print применять по явному запросу на локальный побуквенный ввод,
  с подтверждением точного документа, места и текста перед набором.
- Для многошаговой работы использовать skill-state в текущем чате.
- Учитывать действующее разрешение пользователя на внешние действия
  и обязательные ограничения текущего инструмента.
```

Курс, адрес учителя, разрешение на сдачу и личные сведения лучше задавать
в проекте или текущем запросе, чтобы они не переносились на чужие задания.

## 5. Как работают настройки classroom.json

Файл не является стандартной конфигурацией Codex. Его должен прочитать агент
по инструкции из `AGENTS.md` или `classroom-workflow`. В этом наборе нет общего
исполнителя, который автоматически применяет все JSON-поля к Google Classroom.

| Настройка | Что означает |
| --- | --- |
| `assignment_scope` | Выполнять точные требования задания |
| `preserve_questions` | Сохранять вопросы |
| `copy_when_read_only` | Использовать копию, когда исходник недоступен для записи |
| `text.language` | Брать язык из задания |
| `text.student_age` | Уровень текста для ученика 15 лет |
| `text.style_reference_year` | Ориентир стиля, без изменения реальных дат |
| `text.answer_position` | Ответ непосредственно под вопросом |
| `text.table_selection_marker` | Отметка выбранного варианта знаком `+` |
| `typing.confirm_destination_and_text` | Подтвердить место и текст перед набором |
| `screenshots.attach_to_classroom` | Сейчас `false` |
| `submission.default` | Сейчас подготовка без сдачи |
| `submission.explicit_user_authorization_required` | Сдача требует разрешения пользователя |
| `sharing.teacher_email` | Сейчас `null`, адрес не задан |

Изменение одного поля JSON не подключает API и не выдаёт новых прав.
Правила JSON, `AGENTS.md` и текущий запрос должны согласовываться.

## 6. Для чего нужен каждый навык

| Папка | Когда использовать | Что требуется |
| --- | --- | --- |
| `classroom-workflow` | Полное выполнение задания по его требованиям | Доступ к материалам и подходящие инструменты |
| `text` | Подготовка и редактура ответов | Исходные вопросы и факты, режим Classroom |
| `print` | Внесение проверенного текста по символам | macOS, Python 3, System Events, Accessibility и точное подтверждение |
| `skill-state` | Продолжение длинной работы и checkpoint | Python 3 и локальная папка состояния |
| `humanizer-ru` | Выборочная редактура готового русского текста | Сохранение фактов и жанра |
| `humanizer` | Редактура преимущественно английского текста | Проверка, что стиль подходит заданию |
| `gog` | Google Workspace через CLI | Установленный `gog` и OAuth |
| `google-drive` | Поиск, копии, экспорт и организация Google-файлов | Подключённый Google Drive |
| `google-docs` | Чтение и редактирование Google Документов | Google Drive/Docs инструменты и права на файл |
| `google-drive-comments` | Комментарии, ответы и закрытие комментариев | Явное разрешение на комментарий и подключённый инструмент |
| `google-sheets` | Работа с Google Таблицами | Подключённый Google Drive/Sheets |
| `google-slides` | Работа с Google Презентациями | Подключённый Google Drive/Slides; для части проверок среда исполнения |
| `presentations` | Создание и проверка PPTX | Поддерживаемая среда с `@oai/artifact-tool` |
| `spreadsheets` | Создание и проверка XLSX | Поддерживаемая среда; ограничения и fallback описаны в навыке |
| `pdf` | Чтение, создание и проверка PDF | Poppler и нужные Python-библиотеки |
| `pdf-runtime` | Альтернативный PDF workflow, включая формы | Те же основные библиотеки, дополнительные инструменты среды; имя также `pdf` |
| `playwright` | Управление браузером через CLI | Node.js/npm/npx, браузер и актуальная авторизация |
| `playwright-interactive` | Длительная интерактивная отладка браузера или Electron | Поддерживаемый `js_repl`, Playwright и соответствующая среда |
| `youtube-conversation` | Разбор публичного видео по таймкодам | Совместимое управление пользовательским Chrome и видимая расшифровка |
| `transcribe` | Расшифровка локального аудио | OpenAI SDK и API-ключ для CLI |
| `speech` | Озвучка текста | OpenAI SDK и API-ключ для CLI |
| `imagegen` | Создание и изменение изображений | OpenAI SDK и Pillow для CLI либо доступный инструмент генерации |
| `video` | Подготовка, монтаж и проверка видео | Выбранные видеоинструменты, например FFmpeg; иногда дополнительные плагины |

Для обычного задания не нужно загружать все навыки. Основной маршрут:
`classroom-workflow`, затем `text`, затем один нужный инструмент документа или браузера.
`print` подключается для явно заданного способа ввода. `skill-state` сохраняет
контекст работы и не запускает другой агент или отдельный Codex автоматически.

## 7. Подключение инструментов и зависимостей

### Google Drive, Docs, Sheets и Slides

В доступном каталоге плагинов или подключений установите Google Drive, подключите
нужный Google-аккаунт и проверьте чтение одного своего файла. Навыки Google Workspace
из набора рассчитаны прежде всего на соответствующие подключённые инструменты.
Google Classroom и Google Drive нужно проверять отдельно: доступ к Drive сам по себе
не подтверждает возможность сдать работу в Classroom.

Для Classroom используйте доступное управление авторизованным браузером либо
специализированный инструмент, если он есть в текущей среде. Проверяйте активный
аккаунт, курс, карточку задания и права на документ перед записью.

### gog как дополнительный вариант

Сначала прочитайте `skills/gog/SKILL.md`. В экспортированной версии описан такой маршрут:

```sh
brew install steipete/tap/gogcli
gog auth credentials /absolute/path/to/client_secret.json
gog auth add you@example.com --services drive,docs,sheets
gog auth list
```

Путь и адрес здесь примеры. OAuth client JSON нужно получить и хранить локально
вне репозитория. Для установки актуальной версии сверяйтесь с `gog --help`
и сайтом проекта https://gogcli.sh.
Указанные сервисы ограничены учебной работой с файлами; Gmail и Calendar
добавляйте только при необходимости.

`gog` не является установщиком Classroom и в этом навыке не описан как полный
исполнитель школьных заданий. Экспортированная версия указывает, что для внесения
изменений внутрь Google Документа нужен отдельный Docs API-клиент.

### Побуквенный ввод на macOS

Разрешите необходимый доступ управляющему приложению в системных настройках macOS,
в разделе Privacy & Security / Accessibility. Конкретным владельцем разрешения
может быть терминал, Python или используемое приложение. При запросе System Events
также проверьте разрешение Automation.

Скрипт вставляет по одному символу через текстовый буфер обмена и `Cmd+V`,
а перевод строки отправляет клавишей Return. Он пытается восстановить прежнее
текстовое содержимое буфера после завершения. Это не обещание восстановления
всех типов буфера, например изображения или богатого форматирования.

### Медиа через OpenAI API

Для CLI `transcribe`, `speech` и `imagegen` нужен отдельный `OPENAI_API_KEY`.
Встроенный инструмент приложения может работать другим способом; наличие
подписки Codex само по себе не задаёт эту переменную для Python-скрипта.

В `.env.example` ключи пустые. Создание `.env` не загружает его автоматически
в любой скрипт: переменная должна быть доступна конкретному процессу.
Храните ключ локально, не вставляйте его в чат и не добавляйте в Git.

При необходимости используйте отдельное окружение:

```sh
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install openai pillow reportlab pdfplumber pypdf
```

Устанавливайте только библиотеки для выбранной задачи. Для PDF-рендеринга
на macOS при отсутствии Poppler можно установить `brew install poppler`.
Для видео зависимости определяются выбранным инструментом.

### Навыки, зависящие от исходной среды

`presentations`, `spreadsheets` и часть Google-процессов ссылаются на поддерживаемую
среду артефактов. Копирование инструкции не устанавливает `@oai/artifact-tool`,
`artifact_session` или служебные инструменты.

`playwright-interactive` рассчитан на конкретный `js_repl`. Копия его инструкции
не делает этот инструмент доступным в любом приложении. В экспортированной версии
есть старые требования к запуску; перед применением сверяйте текущую среду,
не меняйте глобальные разрешения ради одного скопированного примера.

`youtube-conversation` описывает работу через совместимую Chrome-возможность
и видимую панель YouTube «Показать расшифровку». Он не содержит собственного
сервера транскриптов. Если такого доступа к Chrome нет, этот workflow нужно
считать недоступным, а другой способ получения материала выбрать явно.

Некоторые экспортированные инструкции используют старые пути `~/.codex/skills`,
`/mnt/data` и имена инструментов прежней среды. Скрипт берите из фактической папки
выбранного навыка. Для регистрации локальных навыков используйте текущие
`.agents/skills` согласно документации Codex. Путь к скрипту и путь обнаружения
навыка выполняют разные роли.

## 8. Как давать задания Codex

### Подготовить ответы без изменения Google

```text
$classroom-workflow $text
Открой задание: [ссылка]. Прочитай формулировку и все вложения.
Подготовь ответы на языке задания, сразу под соответствующими вопросами.
Используй text в режиме Classroom. Покажи готовый текст в чате.
Документы пока не редактируй, задание не сдавай.
```

### Заполнить персональный Google Документ

```text
$classroom-workflow $text $google-docs
Выполни задание: [ссылка Classroom].
Персональный документ: [ссылка Google Docs].
Изучи вложения, подготовь правильные ответы на украинском языке и внеси
их в этот документ через доступный инструмент редактирования.
Сохрани вопросы, нумерацию и таблицы. Проверь весь сохранённый документ.
Задание пока не сдавай.
```

Этот запрос разрешает редактирование указанного документа. Если пользователь
требует побуквенный ввод, вместо обычного инструмента применяется следующий маршрут.

### Внести текст по символам

```text
$classroom-workflow $text $print
Подготовь ответы и введи их посимвольно в документ: [ссылка].
Перед вводом покажи окончательный текст и точные места для каждого ответа,
получи предусмотренное print подтверждение непосредственно перед набором.
После каждого ответа проверь его место и сохранность вопроса. Задание не сдавай.
```

Предварительное разрешение на подготовку работы не отменяет прямое требование
`skills/print/SKILL.md` подтвердить точный текст и место непосредственно перед вводом.
Обязательное подтверждение инструмента также сохраняется. Для остальных действий
действующее разрешение пользователя учитывается в пределах его формулировки.

### Пройти упражнения и сдать конкретную работу

```text
$classroom-workflow $text
Полностью выполни задание: [ссылка], включая приложенные упражнения и тесты.
Разрешаю внести ответы, прикрепить требуемый документ и сдать эту работу.
Скриншоты сохранить в Downloads как testN.png, к Classroom их не прикреплять.
Соблюдай обязательные подтверждения действующего инструмента.
После сдачи проверь видимый статус и сообщи ссылку, результат тестов и статус.
```

Разрешение распространяется на эту работу. Оно не разрешает произвольные
сообщения учителю, приглашения другим людям или сдачу других курсов.

### Подготовить презентацию

```text
$classroom-workflow $text
Изучи задание [ссылка] и подготовь презентацию на украинском языке.
Нужен редактируемый Google Slides / PPTX: [выбрать один формат].
Используй подходящий навык из доступного меню, сохрани требования задания.
Проверь видимые слайды, изображения, читаемость и сохранённый результат.
Задание пока не сдавай.
```

### Разобрать учебное видео

```text
$youtube-conversation
Изучи это видео: [ссылка YouTube].
Ответь на вопросы задания: [вопросы]. Для ключевых утверждений укажи таймкоды.
Если доступная расшифровка неполная, сообщи её пределы и не додумывай содержание.
```

Этот запрос применим при наличии требуемого доступа к Chrome.

### Продолжить длинную работу

```text
$skill-state $classroom-workflow
Продолжи задание [ссылка] из checkpoint [точный путь].
Сначала проверь совпадение задания, актуальный статус документа и разрешения.
Не повторяй уже подтверждённые изменения без причины.
```

## 9. Практические команды скриптов

Все примеры ниже запускаются из корня `classroom`. Указанные файлы в `work/`
нужно предварительно создать или положить туда. Параметры конкретной версии
всегда проверяйте через `--help`.

### print

```sh
mkdir -p work
python3 skills/print/scripts/type_text.py --file work/answer.txt --dry-run
```

После подготовки файла UTF-8, подтверждения точного документа, места и текста,
и установки курсора в нужное поле:

```sh
python3 skills/print/scripts/type_text.py \
  --file work/answer.txt --delay 5 --interval 0.03
```

Через 5 секунд скрипт начнёт ввод в активное поле. Смена фокуса меняет получателя
следующих символов. Для остановки используйте Control-C в управляющем терминале.
Скрипт не проверяет URL документа, не выбирает ответ автоматически и не сдаёт задание.

Параметры `--app`, `--click-x`, `--click-y` и `--document-end` существуют,
но требуют подтверждения соответствующего места. Перемещение в конец документа
не подходит для произвольного вопроса внутри таблицы.

### Имя скриншота

```sh
python3 scripts/next_screenshot_name.py
```

Команда возвращает первый свободный путь `~/Downloads/testN.png`.
Она не снимает экран и не создаёт файл. Настоящий скриншот нужно сохранить
доступным инструментом в возвращённый путь и проверить его содержимое.

### Расшифровка локального аудио

```sh
python3 skills/transcribe/scripts/transcribe_diarize.py --help
python3 skills/transcribe/scripts/transcribe_diarize.py \
  work/lesson.mp3 --language uk --out work/lesson.txt
```

Второй запуск вызывает API при доступном ключе и зависимостях.

### Озвучка и изображения

```sh
python3 skills/speech/scripts/text_to_speech.py --help
python3 skills/speech/scripts/text_to_speech.py speak --help
python3 skills/imagegen/scripts/image_gen.py --help
python3 skills/imagegen/scripts/image_gen.py generate --help
```

Выберите параметры после подготовки текста или промпта. Встроенные инструменты
приложения могут быть удобнее CLI, если доступны в текущей задаче.
Созданная картинка не может заменять доказательство прохождения теста.

## 10. Что считать выполненной работой

Различайте четыре состояния:

1. **Подготовлено:** ответы проверены, но ещё не внесены в Google.
2. **Внесено:** текст находится в нужных местах документа и сохранён.
3. **Прикреплено:** нужный файл виден в карточке нужного задания.
4. **Сдано:** Classroom показывает конечный статус отправленной или выполненной работы.

Для тестов отдельно нужен настоящий итоговый экран. Для презентации нужно открыть
слайды, для таблицы проверить значения и формулы, для PDF проверить страницы и,
если это форма, значения полей. Сообщение об успешном запуске скрипта не заменяет
проверку материала, который увидит ученик или учитель.

Короткий отчёт:

```text
Задание: [название и ссылка].
Выполнено: [документ, вопросы, упражнения].
Результат теста: [фактически показанный результат].
Статус: подготовлено / внесено / прикреплено / сдано.
Осталось: [только реальные незавершённые действия].
```

## 11. Обновление и типичные проблемы

Перед обновлением посмотрите свои изменения:

```sh
git status --short
```

Если рабочая копия чистая и вы хотите получить новый `main`:

```sh
git pull --ff-only
python3 scripts/validate_bundle.py
```

Символические ссылки продолжат указывать на обновлённые файлы. После изменения
навыков проверьте их список; после изменения инструкций начните новый чат.
Не используйте сброс рабочего дерева ради обновления своих изменённых правил.

| Симптом | Что проверить |
| --- | --- |
| Репозиторий возвращает 404 | Это приватный репозиторий; нужен аккаунт с доступом |
| Навык не виден | Есть ли ссылка/папка в `.agents/skills`, доступен ли `SKILL.md`, правильна ли рабочая папка |
| Навык виден дважды | Одноимённые локальные и плагинные версии; особенно два варианта `pdf` |
| Codex не читает правила | Имя `AGENTS.md`, правильный корень и наличие `AGENTS.override.md` |
| JSON игнорируется | Есть ли прямое поручение прочитать `config/classroom.json` |
| `$text` срабатывает как редактор поста | Явно указать режим Classroom и язык задания |
| Google-файл не открывается | Нужный аккаунт, подключение, права и текущая ссылка |
| print пишет не туда | Фокус, выделение, курсор и точное место ввода |
| print получает ошибку System Events | Accessibility и, при необходимости, Automation для управляющего приложения |
| Указан несуществующий скрипт | Старый путь из исходной среды; использовать реальную папку навыка |
| Нет artifact-tool или js_repl | Этот workflow зависит от среды; наличие SKILL.md не устанавливает runtime |
| Слайды экспортированы, но плохо выглядят | Открыть или отрендерить слайды и исправить результат |
| Кнопка сдачи нажата, статус не изменился | Повторно проверить карточку и фактические последствия перед новой попыткой |

Общий лимит проектных инструкций в документации Codex по умолчанию составляет
32 KiB. Поэтому `AGENTS.md` лучше сохранять компактным, а подробные процедуры
держать в `docs/` и навыках, с прямым указанием, когда их читать.

## 12. Ограничения текущего экспорта

В наборе нет универсального установщика и общего автоматического исполнителя
Google Classroom. Правила сдачи и JSON-настройки читаются агентом.

Навык `documents` не экспортирован: причина описана в `docs/export-limits.md`.
Для поддерживаемой работы с DOCX используйте официальный навык/плагин в своей среде.
Не нужно искать его в этой копии `skills/`.

Старые `classroom-map`, `school-tutor`, `biology-exam-rf`, `physics-exam-rf`,
`spellcheck` и ряд школьных скриптов отсутствуют. Этот репозиторий не восстанавливает
их и не содержит личные работы, оценки, профили браузера или авторизацию.
